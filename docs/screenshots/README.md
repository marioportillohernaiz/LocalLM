# Screenshot Files

The root README expects these image files:

- `logo.png`: original large logo source.
- `logo-readme.png`: smaller README-friendly logo generated from `logo.png`.
- `01-sources.png`: Sources screen.
- `02-chat.png`: Chat screen.
- `03-history.png`: History screen.

Keep these files in this directory so the images render on GitHub and other public Markdown viewers.
